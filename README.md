# Del iPhone al escritorio

Laboratorio guiado de macOS con SwiftUI: personaliza una ventana y conecta el menú Nueva tarea con el atajo ⌘N. El proyecto inicial compila y deja pequeños fragmentos de código para que los completes.

## Empieza aquí

1. Obtén la rama **`lab-macos`** y crea tu rama de trabajo siguiendo [la preparación del laboratorio](SEGUNDA_SESION.md).
2. Abre [`codelab/macos.html`](codelab/macos.html) desde Finder: es una guía en español disponible offline.
3. Abre **`macOS/TODOMacLab.xcodeproj`** en Xcode 27.1 y selecciona **My Mac**.
4. Sigue los ejercicios y verifica cada resultado.
5. Guarda al menos dos commits propios y entrega un PR nuevo desde `lab/macos-tu-alias` hacia **main de tu fork**, con las capturas solicitadas.

## Requisitos

Mac con macOS 14 o posterior compatible con Xcode 27.1. El target usa firma para ejecución local; no requiere simulador, iPhone ni Apple Account. Las tareas se mantienen en memoria y vuelven a los ejemplos al salir de la app.

Git, un clon de tu fork y acceso a GitHub. Si cambiaste de Mac, configura tu identidad local de Git. El token temporal anterior puede haber vencido.

No hay dependencias externas ni herramientas adicionales que instalar. La guía y la app funcionan offline; obtener ramas, hacer push y abrir un PR requieren conexión.

Si GitHub muestra una plantilla de PR anterior, reemplázala con `.github/pull_request_template.md` de tu rama actual, como explica la guía.
